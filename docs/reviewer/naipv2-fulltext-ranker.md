# 全文证据 Ranker 实验协议

本实验新增 8B、3B、0.6B 三个全文证据 Ranker。这里的“全文”指从论文正文中确定性抽取并压缩出的结构化证据，而不是把原始 PDF 不加处理地塞进模型。模型输入包括标题、摘要、研究问题与主要贡献、实验设置与数据集、关键结果与结论，最大长度为 1024 token。

## 数据与防泄漏

训练和固定测试集来自 ProReview 的正文 Markdown。训练目标是多位审稿人的总体评分按其置信度加权后的均值；缺少逐条置信度时退化为总体评分均值。训练和测试按照规范化标题与 arXiv ID 去重。

作者、单位、机构、期刊或会议名称、引用与参考文献、审稿文本、meta-review 和录用决定不进入模型输入。会议与年份仅用于构造同组论文对，录用决定仅用于测试 AUC。OpenReview 中附带 `Rejected_Submission`、`Withdrawn_Submission` 等结果后缀的 venue ID 会先统一回基础会议 ID，防止结果通过分组过程间接泄漏。这些字段的角色和数据哈希记录在 `data/naipv2-fulltext-evidence/manifest.json`。

## 训练协议

- 基座：Meta-Llama-3-8B、Qwen2.5-3B、Qwen3-0.6B。
- 方法：8-bit 基座上的 LoRA 成对排序训练。
- 样本：最多 10,000 对；同一会议年份内配对；最低总体评分差 0.5。
- 超参数：1 epoch，学习率 `1e-4`，LoRA `r=16`、`alpha=32`、`dropout=0.05`，随机种子 42。
- 上下文：1024 token；训练与推理均不调用外部大模型，因此 API token 消耗为 0。

## 评测口径

固定测试集报告 AUC、Spearman、NDCG@20、同组两两排序准确率及 bootstrap 95% 置信区间，同时记录训练/推理耗时、输入 token 分布与峰值显存。指标表示模型与留出审稿评分及决定的一致程度，不等于客观论文质量，也不应解释为录用概率。

公开 NAIPv2 测试集和当前 CCF-A/C 1000 对数据只有标题、摘要，没有可验证的开放全文，因此不能冒充为全文评测；后续只有在取得开放或获授权正文后，才能做严格的跨数据集全文测试。

## 服务接口

全文版服务配置位于 `config/ranker-server/fulltext-8b.json`，训练和标定完成后可运行 `npm run ranker:fulltext:serve`，默认端口为 8790。`/v1/paper-scores` 在原有 `paper_id`、`title`、`abstract` 之外接受 `research_question_contributions`、`experimental_setup_datasets`、`key_findings_conclusion`；原摘要版配置保持兼容，客户端不会发送原始全文、作者或录用信息。

## 首轮实验结果（2026-09-02）

三个模型均在同一 998 篇 ProReview 留出测试集上评测，成对准确率使用固定抽样的 10,000 个同组非同分论文对。

| 模型 | AUC | Spearman | NDCG@20 | 成对准确率 | 推理耗时 | 训练耗时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Llama3-8B | 0.5758 | 0.1428 | 0.6566 | 54.86% | 172.1 秒 | 4 小时 14 分 |
| Qwen2.5-3B | 0.5562 | 0.1226 | 0.6142 | 54.10% | 100.0 秒 | 2 小时 21 分 |
| Qwen3-0.6B | 0.5537 | 0.1142 | 0.6381 | 54.30% | 40.5 秒 | 1 小时 2 分 |

8B 在四项指标中整体最好，但成对准确率仅比随机排序高约 4.9 个百分点，尚不足以替换现有线上标题摘要 Ranker。该结果应视为全文证据抽取和训练协议的首轮基线；在部署前需要增加同数据同划分的标题摘要消融实验，并优化证据抽取、训练目标与训练轮数。
