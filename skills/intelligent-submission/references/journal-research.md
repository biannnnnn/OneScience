# Journal and comparable-paper research

Use current web or scholarly data because journal scope, status, fees, and policies change.

## Build the manuscript profile

Extract search concepts rather than copying the abstract verbatim:

- central problem and contribution;
- methods, data modality, population or application domain;
- primary field plus adjacent fields;
- distinctive technical terms and common synonyms;
- article type, where relevant.

Generate several short search queries that combine problem, method, and domain. Do not include author identity or affiliation.

## Discover and verify journals

Discover candidates through scholarly indexes or publisher search, then verify each journal against direct sources. Prefer:

1. the journal or publisher's official aims and scope, author instructions, fees, and policy pages;
2. authoritative indexing records for identity and coverage;
3. OpenAlex, Crossref, or another scholarly index for recent works and persistent IDs;
4. third-party metric aggregators only when the metric's source and year are explicit.

Resolve journal identity using title plus ISSN or another stable source ID where possible. Watch for similarly named journals, title changes, discontinued coverage, special issues, and retracted papers.

Select a differentiated set rather than five near-duplicates. Represent challenge, balanced, and broad-reach options while keeping topical fit credible. Explain which user constraint or evidence makes each candidate useful.

## Retrieve comparable papers

For each journal, search the exact venue and recent date window using multiple profile queries. Prefer research articles with titles, dates, persistent links, and complete abstracts. Exclude retractions, editorials, corrections, calls for papers, and items whose venue identity cannot be verified.

Rank retrieval candidates by topical comparability and query agreement, not citation count. Citation count may be displayed as sourced context when useful but must not affect quality scoring.

Record for each selected paper:

- title and stable paper/source ID;
- publication date or year;
- verified journal identity;
- DOI or persistent landing page;
- abstract provenance;
- search concepts that made it comparable.

If the abstract is missing, continue searching rather than fabricating or scoring it. If the requested `n` cannot be reached, report the actual count and retrieval limitations.

## Fit assessment

Assess fit separately from comparative quality using explicit evidence:

- scope alignment;
- audience alignment;
- article-type and method compatibility;
- practical constraints such as access model, fees, length, data policy, or review format;
- uncertainty or conflicting evidence.

Do not turn prestige tiers or historical acceptance-rate anecdotes into an acceptance prediction. When current authoritative evidence is unavailable, say so.
